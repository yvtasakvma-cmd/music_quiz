# Cadence

iPhone 向けの縦型 PWA。冒頭のメニューで **ケーデンス（ii m7 → V7 → I maj7）**、**メジャーダイアトニック（四和音）**、**平行短調・長調**、**メジャースケール**、**マイナースケール（ナチュラルマイナー）** を選び、音名なしの2オクターブ鍵盤で練習します。問題は最初からランダムで、出題済みの問題は端末に保存されます。ケーデンスとスケールは12キー、ダイアトニックは12キー×7度数の84問、平行短調・長調は両方向24問を一巡するまで重複なく出題し、開き直しても未出題の問題から続きます。最後の問題を採点すると一周分のリザルトを表示します。「もう一回やる」で新しい周を始めるか、「メニューに戻る」を選べます。出題履歴は各クイズで独立しています。キーを手動で選ぶ機能はありません。メニューに戻って別のクイズを選べます。ページを開き直すと必ずメニューが表示されます。

## ケーデンスクイズの使い方

1. 鍵盤の異なる4音をタップして選択。再タップで解除できます。
2. 「鳴らす」で、現在選択した音を同時に確認できます。
3. 「OK」でそのコードを確定。上の丸が黄色になり、次へ進みます。丸をタップすると入力内容を見直せます。編集すると確定が解除されるので、再度 OK を押してください。
4. 3つを確定したら、下の「回答する」で採点。オクターブ・転回形は問いません。同じ音名を複数オクターブで重ねる代わりに、異なる4つの音名を選びます。
5. 採点後は正解の構成音と和音を確認し、同じキーを再練習するか、次のキーへ進めます。

## メジャーダイアトニッククイズの使い方

メニューの「メジャーダイアトニッククイズ」を選びます。「CメジャーのⅡは？」のようにキーとⅠ〜Ⅶの度数が出題されます。対応する四和音の異なる4音を選び、「回答する」で採点します。「鳴らす」で選択中の和音を確認できます。

C の場合は Cmaj7、Dm7、Em7、Fmaj7、G7、Am7、Bm7♭5（Bø7）がⅠ〜Ⅶの正解です。m7♭5 にはハーフディミニッシュの記号 ø7 を併記します。転回形とオクターブは自由です。採点後は正解のコード名・構成音と和音を確認し、同じ問題の再練習か次の問題を選べます。

## 平行短調・長調クイズの使い方

「Cメジャーの平行短調は？」なら A、「Aマイナーの平行長調は？」なら C を鍵盤で1音選び、「回答する」で採点します。オクターブは自由です。別の鍵盤をタップすると選択を変更し、同じ鍵盤の再タップでは解除できます。選択中の音は「鳴らす」、正解の音は採点後の音声ボタンで確認できます。

長調→短調と短調→長調の24問をランダムに出題し、一巡するまで重複しません。他のクイズとは別に出題履歴を保存します。

## スケールクイズの使い方

メニューの「メジャー」または「マイナー」を選択します。出題されたキーのスケールを構成する異なる7音を鍵盤で選び、「回答する」で採点します。始点・終点で同じ音名を重複して選ぶ必要はありません。オクターブは自由です。

「鳴らす」は選択中の音を低い順に再生します。採点後は正解の音名とスケールを確認できます。マイナーはナチュラルマイナー（自然短音階）です。

音は Web Audio で合成し、音源ファイル・外部 API・ログインは使いません。入力中の回答は再読み込みでリセットされます。

## 一周のリザルト

すべてのクイズで、一巡すると「間違えた問題」「正解した問題」の一覧と件数を表示します。問題をタップすると、初回に選んだ音と正解を確認できます。解き直しても最初の採点結果で集計します。ケーデンスは1キーの3コードを1問とし、3コードすべて正解したときにその問題を正解とします。

初回の回答と一周の結果は端末に保存します。終了後に開き直しても、メニューから同じクイズを選ぶとリザルトを再表示できます。「もう一回やる」はそのクイズの結果をリセットして新しい周を開始します。他のクイズの履歴は変わりません。過去の回答記録がない問題は「未回答」として区別します。

## 開発

Node.js 24 と npm を使用します。

```sh
cd /workspace/music_quiz
npm ci --cache /tmp/music-quiz-npm-cache
npm run dev -- --port 5173
```

開発サーバーはポート 5173。本番用ビルドと PWA の確認は以下で行います。

```sh
npm test
npm run build
npm run test:e2e
npm run preview -- --port 4173
```

E2E はモバイル幅の Chromium で、鍵盤選択・解除、実際の AudioContext の和音・スケール再生、メニュー切り替え、両スケールと3コードの採点、編集、やり直し、320px 幅、オフライン再起動を確認します。`/usr/bin/chromium` がある環境ではそれを使います。それ以外では `npx playwright install chromium` でテスト用ブラウザを導入してください。任意の実行ファイルを `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` で指定することもできます。

## iPhone で使う

`npm run build` でできる `dist/` を HTTPS 対応の静的ホスティングに配置してください。サブディレクトリへの配置にも対応します。Safari で公開先を開き、共有メニューの「ホーム画面に追加」を選びます。

初回読み込み時にアプリ本体とアイコンをキャッシュし、以降はオフラインでも起動・出題・再生できます。オフライン機能は本番ビルドでのみ有効です。HTTPS（開発環境では localhost）が必要です。使い方を開くとオフライン準備の状態を確認できます。音が出ない場合は iPhone の音量・消音設定も確認してください。

実機の Safari・ホーム画面からの起動・本体スピーカーの確認は、公開後に行ってください。

## GitHub Pages への公開

このリポジトリには `.github/workflows/deploy.yml` を用意しています。GitHub の [Settings → Pages](https://github.com/yvtasakvma-cmd/music_quiz/settings/pages) で **Build and deployment → Source → GitHub Actions** を有効にしてください。

`main` へ push すると、依存関係の導入・コードのテスト・PWA ビルド後に `dist/` が公開されます。既存の失敗した実行があれば、[Actions](https://github.com/yvtasakvma-cmd/music_quiz/actions/workflows/deploy.yml) から **Run workflow** または **Re-run all jobs** で再実行できます。

標準の公開先は `https://yvtasakvma-cmd.github.io/music_quiz/` です。初回は GitHub Pages の有効化とワークフローの成功が必要です。公開されたら iPhone の Safari で開き、共有メニューから「ホーム画面に追加」を選んでください。
